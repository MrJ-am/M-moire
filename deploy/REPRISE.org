* Mode d'accès retenu depuis Work

L'accès au VPS se fait par GitHub Actions. Work n'a pas d'accès SSH direct ;
les connexions réussies observées sont celles des runners GitHub. Ne pas
retenter SSH depuis Work et ne pas demander de nouveau l'archive privée pour
résoudre cette limitation réseau. Les commandes SSH des relevés historiques
ci-dessous sont destinées aux runners ou à un opérateur local.

Le dépôt VPS propose le workflow ~Auditer le VPS~. Work peut le déclencher
par une demande ~operations/audit-request.json~ publiée sur sa branche ~main~,
puis consulter l'exécution correspondant au commit. La publication de Matheval
et son export chiffré restent gérés par les workflows de ce dépôt sous
~matheval-deploy~, sans droits d'administration du système.

une copie chiffrée a été déchiffrée,
puis restaurée dans une base temporaire : corpus identique, 19 contraintes
présentes et aucune participation initiale. Cette base temporaire a ensuite
été supprimée.

Le propriétaire doit créer le premier compte administrateur avec le lien

HTTP 401. Aucun compte de test ni réponse fictive n'a été ajouté en production.

L'archive privée ~/public/matheval-acces-prives.zip~, hors Git, regroupe les

d'activation. Le propriétaire doit en conserver une copie privée durable
